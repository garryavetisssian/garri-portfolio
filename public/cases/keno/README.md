# KENO case assets

The supplied originals are preserved and all five are included in the authored case at `/[locale]/work/keno`:

- `Cover.png`: hero and iGaming collection cover.
- `Slide 1.png`: full interface presentation.
- `KENO.mov`: game film, native controls, manual playback, metadata preload.
- `Slide 2.png`: numbered-ball artwork in the UI detail chapter.
- `Slide 3.png`: result artwork in the closing chapter.

Supporting user-supplied PNGs are stored unchanged in `/public/case-assets/keno`: statistics, number tile states, empty/completed draws, ready/result grids, empty/placed bets, Quick Bet, and locked/result screens. The component sheets for segmented bars, all 80 balls, countdown variants and the separate background were omitted to avoid repeating information already visible in the main screens.

Case copy is available in English, Russian and Armenian in `src/data/keno.ts`. The narrative describes visible design decisions; it does not assert release status, measured results, project dates, team size or research that was not supplied. The original UI artwork retains its colors in both portfolio themes.
