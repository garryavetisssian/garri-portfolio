# Vivaro.me — recruitment design concept

The Figma Stable page was inspected on 2026-10-08. Its named frames cover five experiences, each in web and mobile: Home — Feed, Home — Play — Casino, Home — Play — Live Casino, Home — Play — Sports, and Challenges — VP Challenges. The file also has Style Guides, UI Kit — Components, Wireframes and Prototype pages. The presence of the Prototype page does not establish that its interactions were tested.

WebP boards preserve the supplied artwork. The four desktop crops remove unused black canvas below the desktop design; mobile crops isolate the companion screen. `Cover.png` is the user's supplied Vivaro brand cover, preserved byte-for-byte at 3840×2160. `Cover.webp` is the earlier social-feed detail and is no longer used as the project cover. Two duplicate sports boards were omitted. Supplemental exported boards remain available even when not featured in the authored narrative.

`CoverEditorial.webp` is the portfolio collection cover, matching the B2B covers' 1600×1000 editorial layout, Unbounded display type, accent glow, metadata and product detail. It is rendered at 2× from `scripts/slides/covers/vivaro.html` using the shared cover stylesheet and the unmodified feed-mobile screen. Regenerate only this cover with `node scripts/slides/covers/render.mjs vivaro.html`. The original supplied `Cover.png` remains the case-study hero and is not overwritten.

The source mapping and mechanical conversion are documented in `scripts/prepare-vivaro-assets.mjs`. Its source paths refer to the supplied temporary PNG attachments; the web-ready files here are retained independently.

No production implementation, user-testing result, retention improvement, reliable sports prediction or commercial outcome is claimed. The AI Assistant is a UI proposal only. Promotional/game imagery is presented as evidence of the design task, not as a live gambling interface.
