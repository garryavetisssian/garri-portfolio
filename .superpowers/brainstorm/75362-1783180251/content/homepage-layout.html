Design Notes

  • Bento Grid Structure: Each section uses bold 2px borders to create distinct visual compartments
  • Hero Layout: 60/40 split - left side for large visual asset placeholder, right side for text content
  • Case Study Display: Bold numbered list (01, 02, etc.) with left border accent and metadata badges
  • Arcade Widget: Integrated games showcase replacing separate mini-games route
  • Typography: Display font for headings, mono for metadata and details
  • Color System: Using existing CSS variables (--ink, --acid, --paper, etc.) for consistency
